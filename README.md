## `// LAB NOTES`

I don't want to collect technologies.

I want to understand **why they exist, how they work, and where they break.**

That means moving between layers:

```text
       APPLICATIONS
             │
             ▼
        FRAMEWORKS
             │
             ▼
          RUNTIME
             │
             ▼
        OPERATING SYSTEM
             │
             ▼
          NETWORK
             │
             ▼
         HARDWARE
```

The interesting part is what happens between them.
