## `// BUILD LOG`

<details>
<summary><b>What is happening inside the lab?</b></summary>

<br>

Axoncron is an evolving technical identity built around experimentation.

The repositories here are not meant to demonstrate that everything has already
been mastered.

They document the process of going from:

```text
"I wonder how this works."
              ↓
"Let's investigate."
              ↓
"Let's build a smaller version."
              ↓
"Why did it break?"
              ↓
"Let's understand the failure."
              ↓
"Let's build it properly."
```

Expect experiments, prototypes, tools, research, systems, and things that
occasionally fail spectacularly.

That's part of the process.

</details>
